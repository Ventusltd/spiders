# Spider Doctrine

This folder carries the identity doctrine for the Spider species lab.

The federation repository remains the first hibernation and recovery source. This repository is where Spider species evolve.

The doctrine files here are intentionally adapted rather than copied as federation paperwork. They carry the operating ideas without importing purchase-order ledgers, scanner mechanics, storage rules or old dashboard-internal naming.

Read these files as a small constitution for future Spider species.

Files in this doctrine set:

- `SPIDER_DNA.md` defines the Spider as an executable metaphor and topology engine.
- `SPIDER_CHARTER.md` defines the lawful boundary, screening-grade claim and governance line.
- `SPIDER_SENSES.md` defines eyes, senses, sources, surfaces and produced artefacts.
- `SPIDER_MAYA_REMOVER.md` defines the duty to remove false appearance.
- `SPIDER_COMMAND_PHILOSOPHY.md` defines command discipline without protected franchise references.

A Spider may look widely, but it must claim narrowly.

Unknown is a real state.

Grey is better than fake green.

# Spider OS

Document type: doctrine

Status: draft operating framework

This folder defines the operating rules for Spider species, scanners, source cards, presentation states, workflows and recovery copies.

The purpose is to make future scanning, presenting and building smooth and consistent across the spiders repo, the federation repo, the GlobalGrid2050 monolith, data repos and future topology species.

Core rule:

The Spider may observe widely, but it must claim narrowly.

Read order:

1. `SPIDER_OS_RULES.md`
2. `DOCUMENT_RULES.md`
3. `EXTERNAL_SOURCE_RULES.md`
4. `SOURCE_CARD_TEMPLATE.md`
5. `SCANNER_RULES.md`
6. `PRESENTATION_RULES.md`
7. `BUILD_SEQUENCE.md`
8. `WORKFLOW_RULES.md`
9. `RECOVERY_RULES.md`

The source-card drafts live in `docs/sources/`.

This OS layer does not change the working Spider UI.

It defines the rails before larger source ingestion, scanning, graph presentation and species builds expand.

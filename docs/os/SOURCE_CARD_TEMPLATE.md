# Source Card Template

Document type: contract

Status: draft template

Copy this template for every source in `docs/sources/`.

```text
Source name:
Publisher / owner:
Primary URL:
Source-card status:
Last checked:
Licence:
Attribution requirement:
Access method:
API key required:
Rate or access limits:
Data type:
Update frequency:
Declared fields:
Derived-only fields:
Known gaps:
Known failure modes:
Allowed Spider use:
Not-allowed Spider use:
Screening boundary:
Notes:
```

## Status values

```text
draft
studied
approved-for-derived-scan
approved-for-declared-reference
deprecated
blocked
```

## Rule

A source-card is not a licence grant.

It records what is known, what is unknown and what the Spider is allowed to do next.

If a source-card is incomplete, the source may be studied but not treated as stable declared truth.
